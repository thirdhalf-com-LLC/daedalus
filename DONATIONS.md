# Support this build

This repository hosts **unofficial, community-built** Daedalus packages (for
example, the macOS Apple Silicon preprod build). It is **not affiliated with or
endorsed by Input Output (IOG)** or the Daedalus team. Daedalus itself is free
and open source.

If these builds save you time, you can buy me a coffee. Donations are voluntary
and help cover CI minutes, an Apple Developer account, and maintenance time.
They do not buy support, warranties, or feature commitments.
